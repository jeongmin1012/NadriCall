나드리콜 이동데이터 기반 페르소나 분석 및 LLM 가상설문
==================================================

AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전

팀명: 딥딥 (DeepDeep)


1. 프로젝트 개요
--------------------------------------------------

본 프로젝트는 대구광역시 특별교통수단 '나드리콜'의 실제 이동데이터를 활용하여 이용자의 이동행동을 분석하고, 이를 바탕으로 합성인구와 LLM 가상설문을 구축한 연구이다.

교통약자의 이동 특성을 데이터 기반으로 유형화하고, 실제 이동행동이 반영된 가상인구를 대상으로 설문조사를 수행하여 기존 설문조사를 보완할 수 있는 가능성을 검토하였다.


2. 연구 목적
--------------------------------------------------

1) 나드리콜 이용자의 시공간 이동행동 분석
2) 장애유형 및 휠체어 이용 여부에 따른 페르소나 구성
3) 실제 이용자 분포를 반영한 합성인구 생성
4) LLM을 활용한 가상설문 수행
5) 실제 설문과 가상설문 응답분포 비교


3. 활용 데이터
--------------------------------------------------

분석 데이터:
2022~2024년 나드리콜 이동데이터

비교 데이터:
2021년 나드리콜 이용자 설문조사

주요 분석 변수:
- 장애유형
- 휠체어 이용 여부
- 이동 시간대
- 평일 및 주말
- 이동거리
- 출발지와 목적지의 공간적 관계

실제 설문조사와 이동데이터의 수집 시점이 다르므로 응답분포의 완전한 일치를 목표로 하지 않았다.


4. 분석 절차
--------------------------------------------------

1단계. 데이터 전처리
- 이동데이터 정제
- 완료 이동건 추출
- 분석 변수 생성

2단계. 페르소나 분석
- 이용자 특성 및 행동 패턴 분석
- 13개 주요 페르소나 도출
- 이동행동 아키타입 구성

3단계. 합성인구 구축
- 실제 데이터의 특성 분포 반영
- A군 합성인구 10,000명 생성
- 프로필 및 행동분포 검증

4단계. LLM 가상설문
- 합성인구별 특성을 반영한 설문 응답 생성
- H4 문항의 최종 응답 조정 및 평가

5단계. 결과 비교
- 2021년 실측 설문과 가상설문 응답분포 비교
- 분포 유사도 및 오차 산출


5. 주요 분석 결과
--------------------------------------------------

최종 분석 결과

- 주요 페르소나: 13개
- 합성인구: 10,000명
- 최종 H4 분포 유사도: 85.55%
- 평균절대오차(MAE): 4.13%p
- 총변동거리(TVD): 14.45%p

위 결과는 최종 H4 응답 처리 과정을 거친 가상설문과 실측 설문 간 분포 비교 결과이다.

이는 이동행동 기반 가상설문이 실제 설문을 보완할 가능성을 보여주지만, 개별 이용자의 응답을 정확하게 예측한다는 의미는 아니다.


6. GitHub 폴더 구성
--------------------------------------------------

01_preprocessing
데이터 정제 및 전처리 코드

02_persona
이동행동 분석 및 페르소나 도출 코드

03_synthetic_population
합성인구 생성 및 분포 검증 코드

04_llm_survey
LLM 가상설문 및 H4 비교 코드

05_results
최종 분석 결과 및 시각화 자료


7. 연구의 한계
--------------------------------------------------

본 프로젝트에는 다음과 같은 한계가 있다.

- 실측 설문과 이동데이터의 수집 시점이 다름
- 이동데이터만으로 개인의 주관적 만족도를 직접 측정할 수 없음
- LLM 응답은 실제 이용자의 응답을 대체하지 않음
- 최종 H4 결과에 응답 조정 과정이 포함됨
- 가상설문 결과의 일반화 가능성에 대한 추가 검증이 필요함


8. 코드 및 데이터 공개 안내
--------------------------------------------------

본 프로젝트는 제한된 데이터 분석 환경에서 수행되었다.

원본 이동데이터는 외부 공개가 제한되어 있으므로 GitHub에 포함하지 않는다.

본 저장소는 실제 연구에 사용한 분석 코드와 공개 가능한 결과물을 제공하여 분석 과정 및 방법론을 공유하는 것을 목적으로 한다.

원본 데이터 및 실행 환경에 대한 접근 제약으로 인해 외부 환경에서 전체 분석을 동일하게 재현하기 어려울 수 있다.


9. 연구 의의
--------------------------------------------------

본 연구는 교통약자의 실제 이동행동을 기반으로 합성인구를 구성하고, LLM 가상설문을 통해 기존 설문조사의 한계를 보완할 가능성을 탐색하였다.

향후 실제 설문조사와 연계한 추가 검증이 이루어진다면, 설문 참여가 어려운 교통약자의 의견을 정책 검토 과정에 반영하기 위한 보조적 분석 도구로 활용될 수 있을 것이다.
