
# 나드리콜 이동데이터 기반 페르소나 분석 및 LLM 가상설문과 수요예측

**2026 AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전**

**팀명: 딥딥 (DipDip)**

## 프로젝트 소개

본 프로젝트는 대구광역시 특별교통수단 '나드리콜'의 이동데이터를 활용하여 교통약자의 이동행동을 분석하고, 이를 바탕으로 합성인구와 LLM 가상설문을 구축한 연구입니다.

실제 이동행동을 반영한 가상설문이 기존 설문조사를 보완할 수 있는 가능성을 탐색하였습니다.

또한 시간대, 지역별 호출 수요와 차량 픽업거리 특성을 분석하여 차량 사전 배치 우선순위와 운영 개선 가능성을 탐색하였습니다.

## 분석 과정

1. 데이터 전처리 및 이동행동 분석
2. 13개 주요 페르소나 및 행동 아키타입 도출
3. A군 합성인구 10,000명 생성 및 분포 검증
4. LLM 기반 가상설문 수행
5. 2021년 실측 설문과 응답분포 비교
6. 시간대별 호출 수요 분석
7. 구.군별 호출 수요 분석
8. 이동기록 기반 픽업거리 분석
9. 수요와 픽업거리 특성을 종합한 차량 사전배치 시사점 도출

## 주요 분석 결과

| 평가 지표 | 결과 |
|---|---|
| 합성인구 규모 | 10,000명 |
| 주요 페르소나 | 13개 |
| H4 분포 유사도 | 85.55% |
| 평균절대오차(MAE) | 4.13%p |
| 총변동거리(TVD) | 14.45%p |
| 오전,오후(06~15시) 요청 비중 | 81.8% |
| 수요 상위 지역 | 달서구, 북구, 동구 |

※ 최종 H4 평가에는 응답 재추론·조정 과정이 포함되어 있으며, 위 지표는 개별 응답 예측 정확도를 의미하지 않습니다.

## 프로젝트 구성

- `01_preprocessing` : 데이터 전처리
- `02_persona` : 페르소나 및 이동행동 분석
- `03_synthetic_population` : 합성인구 생성 및 검증
- `04_llm_survey` : LLM 가상설문 및 H4 평가
- `05_results` : 분석 결과 및 시각화
해당 분석 파일은 `박정민` 폴더에 정리되어 있습니다.
- `06_demand_forecasting` : 수요 분석 및 예측
해당 분석 파일은 `강윤아` 폴더에 정리되어 있습니다.

## 데이터 및 코드 공개 안내

본 연구는 제한된 데이터 접근 환경에서 수행되었습니다.

원본 이동데이터는 공개하지 않으며, 분석 코드와 공개 가능한 집계 결과를 제공합니다.

외부 환경에서는 원본 데이터와 API 접근 제약으로 인해 동일한 분석을 재현하는 데 제한이 있을 수 있습니다.
